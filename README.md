=== Essa é uma versão mais antiga do AutoReCleaner, estou em fase de testes do app e logo será lançado! ===

Essa versão do app consertada do app, a anterior dava erros e ás vezes corrompiam alguns arquivos. É disponível para usuários de Windows. Se o Windows der algum tipo de aviso no momento em que for abrir o app, não se preocupe pois o Windows estranha com tools e apps "que o sistema acha inseguro!". Ainda não recebi demanda de pessoas do linux, mas pretendo fazer uma versão também para Linux e posteriormente para Mac (Se Possível kkkkkk)

Ao entrar no AutoReCleaner escolha a pasta de Origem (De onde os arquivos serão buscados para serem organizados) e pasta de Destino (Onde irão os arquivos dentro da pasta escolhida pelo usuário). A opção de Organizar arquivos coloca os arquivos em suas respectivas pastas de acordo com que pasta de destino que o usuário e escolhe, a opção de remover duplicatas se referem a arquivos repetidos(não sei o porque, mas não consegui para pastas), a opção que junta as duas funções, tanto de organizar quanto a de remover arquivos duplos. Por fim a função de criar pastas necessárias cria automaticamente pasta de documentos, Downloads, Imagens, Vídeos, Músicas, Apps ou Executáveis e as pastas para microsoft office 365 como word, excel e power point.
