# AutoReCleaner
#
=== Essa é uma versão mais antiga do AutoReCleaner, estou em fase de testes do app e logo será lançado! ===

Essa versão do em fase de testes do app, ou seja, essa é a versão Beta, definitivamente não acredito que mude muito, mas houve adições como funções novas, preferências do usuário e muito mais! Adicionei ao projeto funções mais preocupadas nas opções que o usuário pode escolher e condições para organizar melhor as pastas de acordo com cada explorador de arquivos de cada computador usando de regras personalizadas. Também adicionei forma do app monitorar mudanças em tempo real com o watchdog, acredito que agora o usuário tenha mais liberdade no uso. É disponível para usuários de Windows. Se o Windows der algum tipo de aviso no momento em que for abrir o app, não se preocupe pois o Windows estranha com tools e apps "que o sistema acha inseguro!". Ainda não recebi demanda de pessoas do linux, mas pretendo fazer uma versão também para Linux e posteriormente para Mac (Se Possível kkkkkk)

Ao entrar no AutoReCleaner escolha a pasta de Origem (De onde os arquivos serão buscados para serem organizados) e pasta de Destino (Onde irão os arquivos dentro da pasta escolhida pelo usuário). A opção de Organizar arquivos coloca os arquivos em suas respectivas pastas de acordo com que pasta de destino que o usuário e escolhe, a opção de remover duplicatas se referem a arquivos repetidos(não sei o porque, mas não consegui para pastas), a opção que junta as duas funções, tanto de organizar quanto a de remover arquivos duplos. Por fim a função de criar pastas necessárias cria automaticamente pasta de documentos, Downloads, Imagens, Vídeos, Músicas, Apps ou Executáveis e as pastas para microsoft office 365 como word, excel e power point. Nessa versão beta do AutoReCleaner agora é possível adicionar regras personalizadas pelo próprio usuário com o botão adicionar que pode organizar arquivos em subpastas se nas condições o usuário escolher como esse tipo de arquivo começa, termina, se contém algo específico. Se o usuário apertar em Adinionar condição e no lugar de extensão escolher nome e no lugar de igual escolher alguma das opções ditas anteriormente(começa com, termina com...), a opção de tamanho_mb filtra em maior que e menor que, mas ainda está em teste pois não salva as funções ainda. Pode se editar as condições ou até mesmo removê-las se o usuário quiser. Os outros botões estão em fase de testes pois suas funções estão em desenvolvimento ainda, menos o botão de Ativar o Monitoramento, ele está funcionando e responde tudo no log, esse botão monitora mudanças em tempo real na pasta de origem escolhida e de resto tudo certo.
